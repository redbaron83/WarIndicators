# War Indicators

**Conflict signal, not conflict noise.**

War Indicators is a single-file Windows desktop application for conflict early
warning. It tracks **31 indicators across 7 lanes** — medical logistics, energy,
finance, munitions, signatures, vehicles and doctrine — re-states **26 dated
calls** with an independent check on each, and ranks near-term outcomes on a
heuristic confluence score that is **explicitly not a probability**.

Every claim carries a source. Every indicator carries a **falsifier** — the
observation that would prove it wrong. Indicators with no dated evidence on file
say so instead of showing a blank section. The app prints its own data limits,
flags its own noisy matches, and grades its own calls as *self-reported* where no
independent source exists.

It runs from one ~12 MB executable: no installer, no cloud dependency.
